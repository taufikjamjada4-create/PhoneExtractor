# Extract The Spam Phone Numbers From The Videos
Created The Python Project Using The Tesserect-OCR Library To Extract The Spam Phone Numbers From Videos.

## Summary
- First I Created The Python Code To Extract Frames From videos To The Frames Folder If Folder Doesn't Exist It Will Create It.
- After That I Create The Python File And Import The Tesserect-OCR 
- I Clean and Sharpen The Images Collected From The Videos As A Frames.
- At Last Tesserect Extract The Spam Number And Store It In TXT Ans Excel Format.

## Features
- Extract The Frames From Videos.
- Clean and Sharp The Images.
- Extract The Numbers.
- Store In Txt And Excel Format.

## Installation
```bash
pip install -r requirements.txt
```
## Usage

```bash
python main.py
```
